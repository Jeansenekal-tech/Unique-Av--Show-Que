Keyboard & OSC reference

Keyboard

Space / EnterGO – fire the standby cue
↑ ↓Move standby to previous / next cue
EscStop all (with the stop-all fade time)
Shift+EscPanic – stop everything immediately
PPause / resume everything
DelDelete selected cue (edit mode)
Ctrl+LLock / unlock the show

OSC (UDP, default port 53000)

/showcue/goGO. With a number argument: standby that cue and GO
/showcue/cue <n>Fire cue n without moving standby
/showcue/setgo <n>Set standby to cue n
/showcue/next · /showcue/prevMove standby
/showcue/stopall · /showcue/panicStop all with fade / immediately
/showcue/pauseall · /showcue/resumeallPause / resume
/showcue/master <0-100>Master volume

MiX16-style addresses (/mix16showcue/go etc.) are accepted too. Cue numbers match the # column; if none matches, the number is used as a position in the list.

Feedback

When a feedback host is set, the app sends /showcue/standby <number> <name> every time the standby cue changes.
