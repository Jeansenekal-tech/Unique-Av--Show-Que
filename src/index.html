Keyboard & OSC reference

Keyboard

Space / EnterGO – fire the standby cue
↑ ↓Move standby to previous / next cue
EscStop all (with the stop-all fade time)
Shift+EscPanic – stop everything immediately
PPause / resume everything
DelDelete selected cue (edit mode)
Ctrl+LLock / unlock the show
Ctrl+Shift+MMIDI Patch – devices, mappings and monitor (or click MIDI in the top bar)

Pads view

▦ Pads (toolbar)Show every cue as a channel strip with a volume fader. Click the numbered button to play; click it again while it plays to stop it. Folders are the tabs along the top
Pad size − / +Make the pads smaller or bigger (Ctrl + mouse wheel works too). Double-click the % to reset
MIDI LearnClick a pad, then press a key or pad on your MIDI controller. ✕ on a pad clears its key
Esc during MIDI LearnFinish learning

Pads play a cue without moving standby, so GO carries on where it was. Arrange cues and folders in the List view.

Folders

+ FolderMake a new folder (set) after the one you're in
Drag a cue onto a folder barPut the cue in that folder
▾ / ▸ on the folder barClose / open the folder
Double-click the folder nameRename it (works on the folder tabs in Pads view too)

Renaming

Double-click a cue's nameRename the song or cue, in the list or on a pad. Leave it empty to use the file name
Double-click a folder name or tabRename the folder (set)
Click the show name (top left)Change the show's name
Double-click the file name next to itRename the show file on disk

Press Enter to keep a new name or Esc to cancel. Renaming is off while the show is locked.

GO runs straight through: when one folder's last cue has played, the next folder's first cue is on standby.

Waveform (click it first)

Drag green / red markerMove the IN / OUT point
Drag the orange square at the top of INAdd or change the fade-in (or type it in FADE IN)
Drag the orange square near OUTChange the fade-out length
ClickPlace the cursor · double-click previews from there
I / OSet IN / OUT at the cursor
← → (Shift = 1 s)Nudge the cursor 0.1 s
Mouse wheel · Shift+wheelZoom · scroll

Cutting never changes your audio file – it only sets where the cue starts and stops.

OSC (UDP, default port 53000)

/showcue/goGO. With a number argument: standby that cue and GO
/showcue/cue <n>Fire cue n without moving standby
/showcue/setgo <n>Set standby to cue n
/showcue/next · /showcue/prevMove standby
/showcue/stopall · /showcue/panicStop all with fade / immediately
/showcue/pauseall · /showcue/resumeallPause / resume
/showcue/master <0-100>Master volume

MiX16-style addresses (/mix16showcue/go etc.) are accepted too. Cue numbers match the # column; if none matches, the number is used as a position in the list.

Stream Deck / web (http://localhost:53000)

/go · /go/<n>GO · standby cue n and GO
/cue/<n>Fire cue n without moving standby
/standby/<n> · /next · /prevMove standby
/stop · /panicStop all with fade / immediately
/pause · /resumePause / resume
/master/<0-100>Master volume

Stream Deck: use the Website action, paste e.g. http://localhost:53000/cue/3 and tick Access in background.

Feedback

When a feedback host is set, the app sends /showcue/standby <number> <name> every time the standby cue changes.
